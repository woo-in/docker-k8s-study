# 5장. 여러 개의 컨테이너를 연동해 실행해보자

> 도커 엔진이 관리하는 인프라는 컨테이너만이 아니다.
> 컨테이너끼리 이어 주는 **네트워크**와, 데이터를 남겨 두는 **볼륨**도 같은 형식의 명령으로 만들고 지운다.

<br/>

## 네트워크 — 컨테이너끼리 통신하는 길

- 여러 컨테이너를 **연동**하려면 서로 통신할 수 있어야 한다
- 도커 네트워크는 컨테이너들을 **하나로 묶어 주는 가상 네트워크**
- 예: 워드프레스 컨테이너와 MySQL 컨테이너를 같은 네트워크에 연결해 연동한다

### 생성

```
docker network create 네트워크_이름
```

### 삭제

```
docker network rm 네트워크_이름
```

### 목록 출력

```
docker network ls
```

<br/>

## 볼륨 — 컨테이너가 사라져도 남는 저장 공간

- 컨테이너는 **버리고 새로 만드는** 것이라, 안에 저장한 데이터도 함께 사라진다
- 볼륨은 도커 엔진이 관리하는 **컨테이너 바깥의 저장 공간**
- 데이터베이스 파일처럼 남겨야 할 데이터를 볼륨에 저장한다

### 생성

```
docker volume create 볼륨_이름
```

### 삭제

```
docker volume rm 볼륨_이름
```

### 목록 출력

```
docker volume ls
```

<br/>

## 정리

| 인프라 | 역할 | 생성 | 삭제 |
|---|---|---|---|
| **네트워크** | 컨테이너끼리 통신 | `docker network create` | `docker network rm` |
| **볼륨** | 데이터를 컨테이너 밖에 보관 | `docker volume create` | `docker volume rm` |
